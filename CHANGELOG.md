# Changelog

## [0.3.1] - 2026-11-25
### Fixed
- **Bar-axis crack-plane transverse shear (`evaluate_aci318_ch17_anchor_group`):** Removed the legacy `V_guil = 0.0` bypass for `theta_deg < 89.0` and enforced two distinct, unmixed free bodies: (A) concrete anchorage axial tie `T_ult = F_horiz / (cos(theta) + mu*sin(theta)) <= phi_T_bar` (zero shank shear) and (B) direct crack-plane dowel resolution `(N_bar, V_bar) = (F_horiz*cos(theta), F_horiz*sin(theta))` (`N_bar^2 + V_bar^2 = F_horiz^2`) with `ACI 318-19 §17.5.3` brittle strength reduction factors (`phi_N = 0.65, phi_V = 0.60`), `R17.8` `5/3` tension-shear interaction (`<= 1.0`), and `§17.8.3` trilinear interaction (`<= 1.2`) across every embedment angle `theta in (0, 90]`.
- **Single-counted pad-friction equilibrium:** Fixed `V_pry = T_ult * cos(theta) * (1 - mu * tan(theta))` (which subtracted `mu * N_up` twice, understating pryout shear by `-40%` at `45°`, `mu = 0.40`) to exact horizontal equilibrium `V_pry = T_ult * cos(theta) = F_horiz_ult - mu * N_up` (`128.89 kN` vs. legacy `77.34 kN`).
- **Honest negative findings & engineered alternative:** Under Free Body A, `12 x 8 mm` fails `ACI 318 §17.8` concrete interaction (`1.0266 > 1.0`) regardless of shank shear; under direct crack-plane resolution (Free Body B) with brittle `§17.5.3` factors (`phi_N = 0.65, phi_V = 0.60`) and `R17.8` `5/3` interaction, bare unidirectional `45°` CFRP dowels (`tau_ILSS = 75 MPa`) fail transverse shear on both `2 x 8 mm` stitches (`15.51 > 4.52 kN`, `154.32 MPa`, `5/3 = 7.8077`) and `12 x 8 mm` end anchors (`127.60 > 27.14 kN`, `211.54 MPa`, `5/3 = 13.2067`). Upgrading to ISO 898-1 M8×1.25 Class 8.8 steel threaded dowels (`A_se = 36.609 mm²`, `f_uta = 800 MPa`, `ACI 318-19 §17.7.1.2` `0.6*f_uta = 480 MPa`, brittle `§17.5.3` `phi_N = 0.65, phi_V = 0.60` per `§2.3` `12% < 14%` elongation / `ICC-ES ESR-2786` Table 4): `14 x 8 mm` fails brittle material interaction (`5/3 = 1.0775 > 1.0`, trilinear `1.3432 > 1.2`), while **`16 x 8 mm` (`8-pair`)** end groups + `2 x 8 mm` stitches pass all concrete and bar-material gates (end group: `phi_N_stirrups = 593.46 kN`, `phi_Nag = 260.37 >= T_ult = 182.28 <= 304.58 kN`, concrete `interaction = 0.6382 <= 1.0`, `V_bar = 127.60 <= 168.69 kN`, material `5/3 = 0.8625 <= 1.0`, trilinear `1.1753 <= 1.2`; stitches: `T_ult = 22.16 <= 34.18 kN = phi_Nag` & `<= 38.07 kN = phi_T_bar`, concrete `interaction = 0.5616 <= 1.0`, `V_bar = 15.51 <= 21.09 kN`, material `5/3 = 0.8236 <= 1.0`, trilinear `1.1432 <= 1.2`) within `2,421.3 mL` epoxy (`5 x 600 mL` cartridges per `6.0 m` beam for `18` stitches + `32` end dowels).
- Added 2 SymPy symbolic identities (`5` total), 3 physical must-fail controls (`15/15` total), zero-bare-assert R5 regression suite (`tests/test_physical_hardening.py`), and regenerated `results/certificate.json` (`v0.3.1`).

## [0.3.0] - 2026-11-15
### Added
- Resolved Issue #2: coupled 40-station finite-difference longitudinal chord shear-flow solver (`solve_chord_shear_flow_fd`) with full SI `ACI 318M-19 Chapter 17` post-installed adhesive-dowel design (`evaluate_aci318_ch17_anchor_group`: `§17.6.2` concrete cone breakout vs. `§17.5.2.1` closed-stirrup anchor reinforcement, `§17.6.5` `c_Na` group adhesive bond with `ICC-ES ESR-3814` `(fc'/17.2)^0.25` scaling, `§17.5.2.2` `0.55*phi*N_ba` sustained-tension epoxy creep, `§17.7.3` concrete pryout, and `§17.8` `5/3` tension-shear interaction) plus field `600 mL` dual-cartridge epoxy volumetric sizing (`size_dual_cartridge_epoxy`).
- Proved symbolically in SymPy (`verify_symbolic_identities`) that in beam-width-truncated adhesive anchor groups (`b < 2*c_Na`, `s < 2*c_Na`), group bond strength scales inversely with dowel diameter (`d(N_ag)/d(d_a) = -N_ag / d_a < 0`): `12 x 8 mm` `45-deg` dowels deliver `phi*N_ag = 195.76 kN` (`PASS` vs. `182.28 kN`), whereas doubling diameter to `16 mm` cuts `phi*N_ag` by `-43.7%` to `110.23 kN` (`FAIL`).
- Expanded `must_fail_controls` from 8 to 12 (`average_shear_flow_captures_post_yield_chord_gradient_spike`, `oversized_16mm_dowel_increases_width_truncated_group_bond_capacity`, `unreinforced_cover_cone_carries_180kN_end_prestress_without_stirrup_core`, `vertical_90deg_carbon_dowel_survives_guillotine_shear`) and sized complete `6.0 m` beam epoxy demand at `2,288.4 mL` (`4 x 600 mL` dual cartridges).
